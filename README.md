# Devki International

Official website for **Devki International** (`devkiinternational.co.in`), a premier corporate event planning and wedding management company based in Kolkata.

## Highlights
- **Responsive Single-Page Design**: Fast, mobile-friendly showcase of event and wedding services.
- **Direct Client Enquiries**: Integrated WhatsApp click-to-chat and Google Maps location integration.
- **Hosted on GitHub Pages**: Custom domain configured via `CNAME`.
